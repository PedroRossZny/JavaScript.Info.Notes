# Global Object

## Exercise 243

The global object provides variables and functions that are available anywhere. In a
browser it is called `window`, in Node.js it is `global`, and in other environments it
may have a different name. Recently, `globalThis` was added to the language as a standard
name for the global object, which should be supported in all environments. All properties
of the global object can be accessed directly.

In a browser, `var` declarations become properties of the global object, and function
declarations have the same effect — but do not rely on this, as it exists for
compatibility reasons and does not happen in modern scripts. Using `let` avoids this
behavior. If a value is important and needs to be global, write it directly as a property
of the global object. However, the use of global variables is discouraged and should be
kept to a minimum, as shown in **ex243**.
