## Exercise 221

`JSON` (JavaScript Object Notation) is a general format for representing values and
objects, described in RFC 4627. It was created for JavaScript, but many other languages
also have libraries for handling it, making JSON easy to use for data exchange when the
client uses JavaScript and the server is written in Ruby, PHP, Java, or any other
language.

JavaScript provides the following methods:

- `JSON.stringify` — converts objects to JSON.
- `JSON.parse` — converts JSON back into an object.

The resulting string from `JSON.stringify` is called a *JSON-encoded* or *marshalled*
object, ready to be sent over a network or stored in a database.

There are some differences between a JSON-encoded object and a regular object literal:
strings use double quotes — no single quotes or backticks in JSON — and object property
names are also wrapped in double quotes.

JSON supports the following data types: objects, arrays, and primitives: strings, numbers,
booleans, and `null`. Some JavaScript-specific object properties are ignored: methods,
symbolic keys and values, and properties storing `undefined`. Nested objects are supported
and converted automatically. There must be no circular references between objects —
if there are, the conversion fails, as shown in **ex221**.

## Exercise 222

The full syntax of `JSON.stringify` is:
`let json = JSON.stringify(value [, replacer, space])`.

- `value` — a value to be encoded.
- `replacer` — an array of properties to encode, or a mapping function
`function(key, value)`.
- `space` — the number of spaces to use for formatting.

If we need to fine-tune the replacement process, such as filtering out circular
references, we can use the second argument. If the property list gets too long, we can
use a function instead of an array. The function is called for each `(key, value)` pair
and should return the "replaced" value, or `undefined` if the value should be ignored.
The function handles all pairs including nested objects and array items, being applied
recursively. The internal `this` value is the object containing the current property.

The first call is special — it is made using a special wrapper object, meaning the first
pair has an empty key and the entire target object as the value. This gives the system
the ability to analyze and replace or ignore even the entire object if needed, as shown
in **ex222**.

## Exercise 225

To decode a JSON string, we use `JSON.parse`:
`let value = JSON.parse(str [, reviver])`.

- `str` — the JSON string to parse.
- `reviver` — an optional function `(key, value)` that will be called for each pair and
can transform the value.

Common JSON mistakes include: property names without quotes; single quotes on values
instead of double quotes; single quotes on keys instead of double quotes; the use of
`new` is not allowed, only pure values. JSON also does not support comments.

There is another format called `JSON5` that allows unquoted keys, comments, and more —
but it is an independent library, not included in the language specification. JSON is
strict in order to allow easy, reliable, and very fast implementations of its parsing
algorithm, as shown in **ex225**.
