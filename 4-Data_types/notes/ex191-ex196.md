# Map and Set

## Exercise 191

`Map` is a collection of keyed data items, like an `Object`, but with the difference that
`Map` allows keys of any type. Its methods are:

- `new Map()` — creates the map.
- `map.set(key, value)` — stores the value by the key.
- `map.get(key)` — returns the value by the key, or `undefined` if the key doesn't exist.
- `map.has(key)` — returns `true` if the key exists, `false` otherwise.
- `map.delete(key)` — removes the element (key and value) by the key.
- `map.clear()` — removes everything.
- `map.size` — returns the current element count.

Unlike objects, `Map` does not convert keys to strings — any type is allowed. Although
`map[key]` also works, it treats the map as a plain object, implying all the limitations
of one. Therefore we should always use the map's methods.

A `Map` can also use objects as keys, something not possible with plain objects, which
would convert everything to the same string `[object Object]`. The `Map` compares keys
using the `SameValueZero` algorithm, similar to strict equality, with the difference that
`NaN` is considered equal to itself and can therefore be used as a key. This algorithm is
not customizable. Since each `map.set` returns the map itself, calls can be chained, as
shown in **ex191**.

## Exercise 192

To iterate over a `Map` in a loop, there are 3 methods:

- `map.keys()` — returns an iterable for keys.
- `map.values()` — returns an iterable for values.
- `map.entries()` — returns an iterable for entries `[key, value]`, which is the default
for `for..of`.

Iteration happens in the same order the values were inserted. The `Map` also has a
`forEach` method, as shown in **ex192**.

## Exercise 195

`Set` is a special type of collection — a set of values without keys, where each value
can only occur once. Its methods are:

- `new Set([iterable])` — creates the set. If an iterable is provided (usually an array),
it copies all its values into the set.
- `set.add(value)` — adds a value and returns the set itself.
- `set.delete(value)` — removes the value. Returns `true` if the value existed at the
time of the call, otherwise `false`.
- `set.has(value)` — returns `true` if the value exists in the set, otherwise `false`.
- `set.clear()` — removes everything from the set.
- `set.size` — the element count.

The main feature of `Set` is that repeated calls to `add` have no effect — each unique
value appears only once, as shown in **ex195**.

## Exercise 196

We can iterate over a `Set` using `for`, `while`, or `forEach`. There is something
interesting when using `forEach` — the callback function receives 3 arguments: a value,
the same value again, and the target object. The value appears twice for compatibility
with `Map`. The same iteration methods from `Map` are also supported by `Set`:

- `set.keys()` — returns an iterable object for values.
- `set.values()` — same as `set.keys()`, for compatibility with `Map`.
- `set.entries()` — returns an iterable object for entries `[value, value]`, again for
compatibility with `Map`.
