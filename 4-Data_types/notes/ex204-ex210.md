# Destructuring Assignment

## Exercise 204

Two very commonly used data structures are Objects and Arrays. However, when we pass this
data to a function, we may not need all of it. For that we use *destructuring assignment*,
a special syntax that allows us to unpack arrays or objects into multiple variables.

We can work with variables instead of array elements, which works very well with methods
that return arrays. In destructuring, we are copying the items into variables — the
original array is not modified. Unwanted elements can also be discarded with an extra
comma. Destructuring can be used with any iterable, such as a `Set`, since internally it
works by iterating over the value on the right side. We can also assign to anything on
the left side, such as an object property.

We can also use `Object.entries(obj)` with destructuring to iterate over the key/value
pairs of an object. This is even simpler with a `Map` since it is already iterable.

There is also a trick to swap the values of two variables using destructuring — by
creating a temporary array of two or more variables and immediately destructuring it with
the order swapped, as shown in **ex204**.

## Exercise 207

Destructuring also works with objects, using the syntax
`let {var1, var2} = {var1:..., var2:...}`. We place an existing object on the right side
and on the left side we use a pattern matching the object's properties — a list of
variable names inside `{...}`. The properties are assigned to the corresponding variables,
and the order does not matter.

The left side pattern can be more complex — we can assign a property to a variable with a
different name using a colon, indicating what goes where. For potentially missing
properties, we can set default values using `=`. Default values can be any expression or
even function calls, which are only evaluated if no value is provided. We can also combine
the colon and the equals sign together. If we have a complex object, we can extract only
what we need, as shown in **ex207**.

## Exercise 208

Just like with arrays, when an object has more properties than variables we use `...` to
assign the rest of the object to a variable. In the examples seen so far, variables were
declared directly in the assignment. We could also use existing variables without `let`,
but this normally would not work — JavaScript treats `{...}` in the main flow as a code
block used to group statements. Without `let`, JavaScript assumes we have a code block
and throws an error. To prevent this, we can wrap the expression in parentheses, as shown

## Exercise 210

There will be times when a function has many parameters, most of them optional. Writing
such a function the usual way makes it hard to remember the order of arguments, and
calling it when most parameters have valid defaults becomes messy and hard to read.

In such cases we use destructuring — we can pass parameters as an object and the function
immediately destructures them into variables. More complex destructuring with nested
objects and colon mappings is also possible.

The syntax is the same as a regular destructuring assignment:
`function({ incomingProperty: varName = defaultValue ... })`. For a parameter object,
there will be a variable `varName` for the property `incomingProperty`, with `defaultValue`
as the default. This destructuring assumes the function is called with at least an empty
argument — if we want all default values, we must pass an empty object, otherwise an
error will occur. We can fix this by setting `{}` as the default value for the entire
parameter object, as shown in **ex210**.
