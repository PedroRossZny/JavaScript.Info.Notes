# Object.keys, values, entries

## Exercise 202

We have already seen the methods `map.keys()`, `map.values()`, and `map.entries()`. These
methods are supported for `Map`, `Set`, and `Array`. Plain objects also support them, but
with a different syntax.

For plain objects the available methods are:

- `Object.keys(obj)` — returns an array of keys.
- `Object.values(obj)` — returns an array of values.
- `Object.entries(obj)` — returns an array of `[key, value]` pairs.

Besides the syntax difference, the return value is also different from other data
structures — with `Map` these methods return an iterable, while with plain objects they
return a real array.

The syntax is different for flexibility reasons: a plain object could have its own
`values()` method, and calling it as `data.values()` would call that method. Using
`Object.values(data)` avoids this conflict.

These methods ignore `Symbol(...)` keys. For symbols there is a separate method,
`Object.getOwnPropertySymbols`, which returns an array of only symbolic keys, and
`Reflect.ownKeys(obj)` which returns all keys, as shown in **ex202**.

## Exercise 203

Plain objects do not have array methods like `map`, `filter`, and so on. If we want to
use them on an object, we need to follow these steps:

1. Use `Object.entries(obj)` to get an array of key/value pairs from the object.
2. Apply array methods such as `map`, `filter`, and others on that array.
3. Use `Object.fromEntries(array)` on the resulting array to convert it back into an
object.
